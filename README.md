# 飲食日記 🍽️

一個根據個人體質給予食物評分的飲食記錄 PWA（單檔 HTML，純前端）。

## 功能

- **拍照辨識**：上傳食物照片，AI 自動辨識並依體質評分（需 Anthropic API）
- **手動記錄**：常用食物快速新增、卡路里與餐次記錄
- **健康評分**：依「非常適合 / 適合 / 還可以 / 建議避免」四級給每日評分
- **歷史與統計**：逐日回顧、本週健康趨勢、最常吃食物排行
- **體質建議**：針對腸胃敏感、偏熱體質的飲食原則

資料儲存在瀏覽器 `localStorage`，不上傳伺服器。

## 使用

直接開啟 `index.html` 即可，或部署到任何靜態主機（GitHub Pages、Netlify、Vercel）。

## 檔案

- `index.html` — 完整應用程式（HTML + CSS + JS 單檔）

> 註：`index.html` 中引用了 `manifest.json`、`sw.js`、`icon-192.png` 以支援 PWA 安裝，這些檔案為選用，缺少時不影響主要功能。
